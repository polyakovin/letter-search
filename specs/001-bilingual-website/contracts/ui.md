# Public UI contract
- Root locale is Russian. `en/` is English. Both pages work under the `/letter-search/` prefix.
- Navigation anchors: #how, #demo, #together, #custom. Telegram CTA targets https://t.me/letter_search_bot and clearly identifies Russian-language service in English copy.
- Demo scene selector, Start, word form, Finish, Replay and Enlarge are keyboard accessible. Timer is visual; screen reader announces state and submissions, not every second.
- A running round is reset on scene/locale change with visible explanation. Final result presents confirmed count, accepted words and example answers; no authoritative rejection of unlisted nouns.
- Custom section uses the exact requested asset. Contact link is external and no form collects personal data.
