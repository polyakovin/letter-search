# Decisions
- **Static HTML + modules**: Fits GitHub Pages and instant no-account demo; no framework or hosted service required. Build-time localization preserves indexable copy and no-JS explanations. Rejected SPA-only content and external API validation.
- **Curated vocabulary**: Deterministic local checking with aliases grouped by physical object, distinct unlisted feedback and human discussion cue. No claim of exhaustive image recognition.
- **Independent public repository**: GitHub API confirmed user-specified target is empty/public and source bot repository private. Do not publish bot source or git history.
- **English illustration adaptation**: Reuse studio/winter compositions; add unmistakable C/S objects and visually validate answer catalogs. Preserve Russian and custom originals.
- **GitHub Pages Actions**: Follow https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages ; upload only dist, separate build/deploy with minimal permissions.
